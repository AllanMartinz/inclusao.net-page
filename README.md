# 🌐 Inclusão.net

Projeto acadêmico com foco em **inclusão digital e acessibilidade na web**.  
O site foi desenvolvido utilizando **HTML5, CSS3 e JavaScript** e contém recursos que promovem a navegação acessível para diferentes públicos.

## 📌 Estrutura do Projeto

- `index.html` → Página inicial com informações, cadastro, feedbacks e notícias.  
- `about.html` → Página "Sobre", apresentando missão, visão e equipe.  
- `register.html` → Página de cadastro de usuário com validação básica.  
- `accessibility.html` → Página dedicada a explicar recursos de acessibilidade.  
- `style.css` → Folha de estilo principal do site.  
- `scripts.js` → Funcionalidades em JavaScript para acessibilidade (contraste, tamanho de fonte, atalhos).  
- `images/` → Pasta de imagens utilizadas no site.  

## 🎯 Funcionalidades

- **Controle de acessibilidade**:
  - Aumentar e diminuir fonte (`A+ / A-`).
  - Alternar para modo de **alto contraste**.
  - Atalhos de teclado (`Ctrl + +`, `-`, `C`) para acessibilidade.
- **Formulários**:
  - Cadastro de usuários.
  - Envio de feedbacks.
- **Links rápidos** para redes sociais.  
- **Responsividade**: Layout adaptado para desktop e mobile.  
- **Semântica e ARIA roles** para leitores de tela.  

## 🛠️ Tecnologias Utilizadas

- **HTML5** (semântica e acessibilidade com ARIA)  
- **CSS3** (responsividade e temas de contraste)  
- **JavaScript (ES6+)** (controle de acessibilidade e atalhos)
